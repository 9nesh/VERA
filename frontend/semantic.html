Index NEPA Documents into Actian VectorAI DB

This pipeline reads all documents from the VERA SQLite database, splits them into 600-character chunks with 80-character overlap, embeds each chunk using OpenAI text-embedding-3-small (1536d), and stores the vectors in Actian VectorAI DB for fast K-NN semantic search.

  1. Ensure Actian VectorAI DB is running: docker compose up -d
  2. Set your OpenAI key: export OPENAI_API_KEY=sk-…
  3. Ingest NEPA documents into SQLite first (run the ingest script)
  4. Click Start Indexing below — or run python scripts/index_to_vectorai.py --reset from the CLI
